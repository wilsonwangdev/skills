# 行为验证

按技能保存代表性请求、必要上下文与可观察的结果。修改技能行为时，使用对应材料做受控试用；新增技能的材料约定见 [维护指南](../CONTRIBUTING.md)。

## 案例目录

- [learn-from-agent-conversations](learn-from-agent-conversations.md)：概念追问、纠正原回答、缺少前文、直接解释与非学习请求。

## 记录结果

记录技能版本、使用的场景、Agent 的实际回复或任务结果，以及尚未覆盖的边界。优先检查是否实现预期行为，不机械匹配固定措辞。

静态检查只证明结构和引用满足检查规则。受控试用、客户端实际加载、工具执行与真实用户反馈各自提供不同证据；结论应与已完成的验证相符。

试用使用合成材料或可公开输入；外部操作沿用当前任务的授权范围。临时产物可以留在临时目录，公开记录应去除身份信息、私有上下文和凭据。
