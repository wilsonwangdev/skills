# 学习材料整理

仅在用户要求保存笔记、完整报告或专题文档时读取。日常互动默认留在会话，不把一次追问自动扩展成文档项目。

## 围绕疑问组织

交代读者起点、原始疑问和来源范围，然后连接直接解释、具体例子、必要概念与适用边界。篇幅由理解任务决定；只有独立学习目标才拆篇，不按术语数量或固定模板机械生成系列文档。

保存本次已经建立的理解，补充仍未解释的点。练习与参考解读按用户需要提供，不把“材料已交付”写成“知识已掌握”。

## 复查阅读负担

按主技能的概念与语言规则检查正文、图示、表格和练习。沿首次阅读的顺序，检查每个关键概念是否在参与推理前得到说明；必要前提应紧邻使用处，不能只藏在文末概念表或外链里。

一段解释依赖多个未知术语时，缩短推理路径、补最小背景或换成具体例子。优先复用已经建立的概念，不断换用抽象名称会使文字变短、理解却更困难。

语言简洁且术语一致。保留原文或标识用于准确定位，不把它当作读者已经理解的证据。来源链接承担追溯，不代替必要说明。

## 来源与交付

准确区分原文事实、示意假设、已核实结论和待确认内容。外部实现不可见时保留边界，原回答有误时先修正，不把错误固化进笔记。

使用用户指定且当前可用的文档工具，遵循其创建、局部更新与回读流程；无法写入时保留完整本地稿并说明具体阻塞。已有同主题材料优先更新，避免重复创建。

共享稿只保留理解所需的信息，移除个人背景、机器路径、私有标识及凭据。按明确的位置与权限交付，不自动扩大分享范围或广播链接。长期学习档案及复习日程由用户另行决定。
